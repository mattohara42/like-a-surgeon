# M1, session 4: audit the batch

Run after you have read the batch report yourself. Reading it yourself first
matters, because this prompt asks the agent to critique its own work and you
want your own view before you see its view.

---

Audit batch 1 adversarially. Assume it is worse than it looks and find where.

Do not fix anything yet. Report first.

1. Search every file added in batch 1 for quotation marks around attributed
   speech. List every instance with its file. If there are none, say so
   explicitly.

2. For every edge tiered `documented`, state in one line what the actual
   documentation is. Any edge where you cannot name a real interview, credit,
   liner note, lawsuit, or equivalent gets downgraded to `consensus`. List the
   downgrades.

3. Report the tier ratio. If `documented` is above about 30 percent, explain
   why that is defensible here or accept that it is inflation.

4. Identify the five weakest `whatToListenFor` fields in the batch. Weakest
   means it would apply equally well to two other records. Quote them and say
   what specifically is missing.

5. Identify anything you wrote that reads as praise rather than description.
   The hook field states what an artist changed, not whether the music is good.

6. Identify any place where the Teen register contains fewer facts than the
   Adult register rather than simpler words for the same facts.

Give me the report. I will tell you which fixes to make.
